# 邮件模板

## 通用规则

- 直接给主题和可编辑正文，用业务语言，不附证据编号。
- 只写收件人能知道的事实和双方约定。内部风险、角色猜测、他人私下意见和比较对象留在内部。
- 我方承诺照原样写日期。客户没承诺的事用提议或问句，例如「方便的话，烦请告知…」。
- 没有原话时不用引号冒充客户原话。缺收件人姓名时用通用称呼。
- 每封邮件最多一个主要请求。结束或暂缓时可以仅确认买方决定和我方履约事项；必要时附一个低门槛的替代选项。
- 正文控制在 200 字左右。

## 按场景

| 场景 | 结构 |
| --- | --- |
| 需求沟通后 | 感谢 → 复述对方确认的业务问题和目标 → 我方下一步及日期 → 请求下一位参与者或下一次会面。 |
| 演示后 | 感谢 → 已演示的范围 → 对方想验证的工况 → 我方要交付的材料及日期 → 请求样件、环境或验收人。 |
| 报价后 | 报价版本和范围 → 待答条款 → 请求评审时间和参与人。 |
| 客户未回复 | 一两句提醒上次的约定 → 低门槛选项，例如「回复一个方便的时段即可」。不加压，不重复全部内容。 |
| 客户拒绝或暂缓 | 确认买方决定及尚待兑现的我方承诺；有买方约定的联系条件时再复述。 |
| 客户附加条件 | 确认已理解的条件 → 我方的应对或需要澄清的问题 → 下一步请求。 |

产品相关的请求用语见[产品参考](products.md)里各产品的「邮件请求」。
