# 质量自检

交付前在客户端静默检查。发现问题就修正后再展示，不向用户输出自检结果。

| # | 条目 | 检查内容 |
| --- | --- | --- |
| 1 | 主体 | 法定主体已确认。同名、集团、子公司的材料没有拼接。 |
| 2 | 事实与假设 | 事实带来源和日期。切入假设、现场问题和推断标为待验证，不说成已确认。 |
| 3 | 证据边界 | 没有把招聘当采购意向，把融资当预算，把专利署名或职位当现任职务和决策权，把个人经历当企业部署，把 Owner 当引荐关系。详见[证据边界](evidence-limits.md)。 |
| 4 | 时效 | historical、unknown、stale 和 changed、unavailable 都保留了限定。缺失没有写成「不存在」或「无需求」。 |
| 5 | 完成状态 | 受理没有写成已生成。`partial` 写明覆盖范围。没有承诺后台补齐。 |
| 6 | 排名 | 机会等级和置信度没有写成成交概率。联系条件没有参与排名。资料不足的企业没有被硬塞进排名。 |
| 7 | 限制 | 关键警告、准备限制和必要问题都在，且压缩成了短句。 |
| 8 | 篇幅 | 符合[展示格式](display.md)：结论先行，事实不重复，限定语合并，没有内部 ID 和哈希，没有空章节。 |

常见问题见[正反例](examples.md)。
